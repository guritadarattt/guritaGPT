# 🐙 Gurita GPT

Asisten AI berbasis GPT-J-6B (ONNX Q4) dengan antarmuka web lengkap.

## Fitur

- 🏠 Dashboard status server & model
- 📚 Dokumentasi API untuk developer
- 💬 Chat multi-conversation dengan judul otomatis
- 🔐 API Key management (tanpa login platform)
- 👑 Panel admin untuk monitoring & training
- 🌐 Pencarian internet real-time (DuckDuckGo)
- 🎭 Persona & karakter yang bisa dikustomisasi

## Instalasi

```bash
git clone https://github.com/guritadarattt/guritaGPT.git
cd guritaGPT
npm install
npm start
