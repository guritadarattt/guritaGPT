🐙 Gurita GPT — API Documentation

Endpoint chat untuk Gurita GPT. Butuh API Key dari admin.

POST /api/v1/chat

Headers:
  X-Api-Key: gptj_xxxxxxxx
  Content-Type: application/json

Body:
{
  "message": "Siapa presiden Indonesia saat ini?",
  "use_search": true,
  "max_tokens": 256
}

Contoh cURL

curl -X POST http://localhost:3000/api/v1/chat \
  -H "X-Api-Key: gptj_xxxx" \
  -H "Content-Type: application/json" \
  -d '{"message":"Halo","use_search":true}'

POST /api/v1/conversations

Buat percakapan baru (multi-chat).

POST /api/v1/conversations
Headers: X-Api-Key
Body: { "title": "opsional" }

POST /api/v1/conversations/:id/messages

Kirim pesan dalam percakapan tertentu.

Body:
{
  "message": "Hai Gurita",
  "use_search": false,
  "max_tokens": 256
}

use_search: true akan mengaktifkan pencarian internet real-time agar Gurita GPT tidak ketinggalan informasi terbaru.
